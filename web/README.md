# Campus Orbit — Web Application (React 19 + TypeScript + Vite + Tailwind CSS)

This `/web` directory contains the standalone Progressive Web Application (PWA) version of **Campus Orbit — Unified Multi-Role Academic Operations & Smart Campus Management System**, including the full 9-tab **Campus Collaboration Hub**.

## Quick Start (Local Development)

1. Navigate to the `/web` folder:
   ```bash
   cd web
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. (Optional) Copy `.env.example` to `.env` and add your Firebase Web API key to connect live to project `gen-lang-client-0129438987` and database `ai-studio-android-campusor-dbbd9944-1354-4514-889d-28880eb13b05`.
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open `http://localhost:5173` in your browser.
